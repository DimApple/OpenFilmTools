Installation & documentation

OpenGate · Windows / Linux

Extract the source. Install Node.js 22.12 or newer and npm. Open a terminal in the extracted app folder.

npm ci
npm run build
npm run desktop

For portable builds: npm run desktop:package -- linux or npm run desktop:package -- win32. See the included docs/BUILD_INSTRUCTIONS.md and README for details. Desktop installers are not included in this repository.

OpenTake · Web / Android

Launch the web app over HTTPS. Use your browser’s install or Add to Home Screen option where supported. On Android, download the preview APK and allow installation from the chosen source if prompted; review the file before installing. Export .otake backups regularly: clearing browser data can erase records.

For development, use Node.js 24 and run:

npm ci
npm run dev -- --host 127.0.0.1

See the included README and android/README.md for details.

OpenRoll · Windows / Linux

Native Qt application. Windows requires Visual Studio 2022 C++ tools, Qt 6.8+, Python, Meson, Ninja, VLC 3 SDK, FFmpeg and the separately obtained Blackmagic RAW 6.0 SDK. Follow docs/WINDOWS.md in the source archive. Linux instructions are in README.md, including CachyOS dependencies and SDK extraction.

Use expendable test footage before relying on verified ingest or transcode on a real production. Never erase original media based solely on a preview application.

Release status

These are development checkpoints, not certified production releases. Source archives were collected from existing project files; this website assembly did not rebuild or retest the applications. Windows/Linux desktop binaries are withheld from this repository pending release and dependency review. Each application retains its own upstream notices and applicable terms.
