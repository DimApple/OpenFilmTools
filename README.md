# OpenFilm

**Open tools for independent filmmakers.**

OpenFilm is a collection of filmmaking applications designed to make production workflows more accessible to independent filmmakers, students, and small production crews.

The project brings together tools for pre-production, on-set production logging, and digital media management without requiring expensive software subscriptions.

**Website:** https://dimapple.github.io/OpenFilmTools/

## Applications

### OpenGate — Levi Edition

**Screenwriting and pre-production**

A customized edition of OpenGate designed to centralize the creative and organizational aspects of filmmaking.

Features include:

- Screenplay writing and formatting
- Script organization
- Shot lists
- Storyboarding
- Lined script PDF export
- Production planning
- Automatic project saving
- Dedicated workspaces

**Supported platforms:** Windows and Linux.

#### Installation

**Windows:** Download the Windows package from the Releases page. Extract the archive and launch the application, or run the installer if one is provided.

**Linux:** Download the Linux package from the Releases page. Extract the archive and launch the included executable. Flatpak packages may also be available depending on the release.

---

### OpenTake

**On-set production and take logging**

OpenTake is a lightweight digital production logging application designed for camera assistants, script supervisors, and independent production crews.

Features include:

- Scene, shot, and take logging
- Take ratings and production notes
- Automatic saving
- Batch selection and management
- Production report exports
- Mobile-friendly interface
- Desktop and mobile browser support

**Supported platforms:** Android, Windows, Linux, macOS, and iOS through a compatible web browser.

#### Installation

**Web:** Open the web application through the OpenFilm website. No installation is required.

**Android:** Download the APK from the Releases page and open it on your device. Android may require permission to install applications from external sources.

**Desktop:** Open the web application in a compatible browser. Browsers supporting Progressive Web Apps may allow OpenTake to be installed as a standalone desktop application.

**iOS:** Open the web application in Safari and select Share → Add to Home Screen.

---

### OpenRoll

**Digital imaging and media management**

OpenRoll is a lightweight media playback and transcoding application intended for digital imaging technicians, camera departments, editors, and independent filmmakers.

Features include:

- Production media playback
- Camera footage review
- Blackmagic RAW support
- Media transcoding
- Proxy generation
- FFmpeg integration
- VLC-based media playback
- Streamlined production-oriented interface

**Supported platforms:** Windows and experimental Linux builds.

#### Installation

**Windows:** Download the Windows installer from the Releases page, run the installer, and launch OpenRoll from the Start menu.

**Linux:** Where available, download the appropriate Linux package for your distribution. Linux support is currently experimental.

Camera format compatibility and transcoding capabilities may vary depending on the installed version and included dependencies.

## Production Workflow

The OpenFilm applications are designed to complement one another throughout the filmmaking process.

| Production Stage | Application | Purpose |
|---|---|---|
| Pre-production | OpenGate | Writing, storyboarding, and planning |
| Production | OpenTake | Logging scenes, shots, and takes |
| Production / Post-production | OpenRoll | Reviewing and transcoding footage |

Each application can be used independently.

## Project Philosophy

Filmmaking tools should be accessible regardless of a filmmaker's budget.

OpenFilm prioritizes:

- Accessibility
- Practical filmmaking workflows
- Cross-platform compatibility
- Simple, functional interfaces
- Independent development
- Freedom from mandatory subscriptions

## Development Status

OpenFilm is an independent project under active development. Applications may contain bugs, incomplete features, or platform-specific limitations.

Always maintain independent backups of important production files. Verify application functionality before relying on it during a professional production.
